# Student Grade Management System

A beginner-friendly Python project that demonstrates Object-Oriented Programming through a simple student grade management system.

## Features

- Create a student object
- Store student information
- Store marks for multiple subjects
- Display student details and marks
- Update marks for individual subjects
- Calculate the average marks
- Determine the student's grade
- Handle invalid subject names

## OOP Concepts Used

This project demonstrates:

- Classes and objects
- `__init__()` constructor
- Instance attributes
- Instance methods
- Updating object attributes
- Method calls
- Returning values from methods
- Conditional statements
- Basic calculations

## How It Works

The project contains a `Student` class that stores the student's information and marks.

### Student

The `Student` class stores:

- Student name
- Roll number
- Mathematics marks
- English marks
- Science marks

It provides methods to:

- Display student information
- Update subject marks
- Calculate the average
- Determine the grade
